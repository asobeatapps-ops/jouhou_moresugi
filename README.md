# 情報、漏れすぎ。 / ASOBEAT

安全なら押す。危険なら見送る。会社の命運を任された情報セキュリティ担当の、判断アクションゲームです。全15エンディングと収集図鑑を備えた、サーバー不要の公開MVPです。

想定公開先：https://asobeatapps-ops.github.io/jouhou_moresugi/

## 遊び方

1. 「出勤する」で開始。部長の引き継ぎチャットは初回6秒、以後2秒。タップでスキップできます。
2. 安全な操作は中央のボタンをタップ。危険な操作は時間切れまで何もしません。PCはクリック、Space／Enterにも対応。
3. 正解で得点とコンボが増え、3ミスで通常終了。特殊な操作で別の結末にも分岐します。
4. 結果や図鑑から再挑戦。未発見カードには攻略ヒントがあります。

プレイは3ミスまで続くエンドレス方式です。30〜60秒は通常プレイの目安で、固定の時間制限ではありません。全30通常問題をシャッフルし、安全・危険の連続偏りと直近8通常問題の重複を抑制します。7問目には保存されたプレイ回数に応じた9周期の特殊ルート、必要な場合は8問目にその続きが出ます。7問目より前に終了した場合でも出勤回数は進みます。

## ローカル起動

```sh
python3 -m http.server 8020
```

http://localhost:8020/ を開きます。ES Modulesを利用するため、`file://`で直接開くのではなくHTTPサーバーかGitHub Pagesを利用してください。npmによるビルドや外部ライブラリの読み込みは不要です。

## ファイル構成

- `index.html`：タイトル・プレイ・END・図鑑の4画面
- `css/style.css`：スマホ中心のレイアウト、Safe Area、VFX、動きを減らす設定
- `js/data.js`：通常30問・特殊11問、15ENDとヒント
- `js/engine.js`：出題・進行・得点・操作競合・END優先順位
- `js/main.js`：DOM、入力、画面遷移、フォーカス管理・時間停止
- `js/art.js`：Canvasによるオフィス、人物、15種類のENDアニメーション
- `js/audio.js`：オリジナル生成BGM／SE、音声解除・停止
- `js/storage.js`：ブラウザ保存と失敗時のメモリ継続
- `assets/favicon.svg`：自作アイコン
- `privacy.html`：データ取り扱い
- `tests/`：外部依存のないNode.jsテスト
- `DEVELOPMENT_SPEC.md`：受領した承認済み仕様
- `QA_REPORT.md`：検証結果と未実施項目

## 判定・時間の設計

1問の時間は `max(1200, 3000 - 75 × (問題番号 - 1))` ms。正解時の加点は1〜5コンボ100、6〜10で200、11〜15で300、16〜20で400、21以上500です。正誤判定は1回、判定待機400ms、各ENDアニメーション3000ms。真END→隠し→特殊→通常の優先順位で一度だけ確定します。

通常タップは離した時点で判定します。HS-01は1500ms以上の継続、HS-02は指を離した2回のタップの間隔240ms以下です。HS-02の1回目は通常判定し、400msの判定中に限って2回目の隠し操作を受け付けます。2回目は再採点しません。締切と入力が同時なら時間切れを優先します。

問題ごとのトークンと単一ステートマシンで古い入力を無効化し、問題進行のsetTimeoutは使いません。タブ移動・フォーカス喪失でプレイを停止し、再開ボタンで戻ります。回転・リサイズ・pointercancelでは押下状態を解除します。画面内でスクロールを捕まえるのではなく、主ボタンのtouch-actionで誤操作を抑えます。結果と図鑑は小さい画面で縦スクロールできます。

## 保存・音声・プライバシー

`asobeat_jouhou_moresugi_v1` に発見END、自己ベスト、最大コンボ、音声設定、出勤回数、直近50回の結果を保存します。保存拒否・破損時もメモリ上で継続し、保存できない旨を表示します。リロード・端末間での引き継ぎはブラウザ保存の範囲に限られます。

Web Audioはユーザー操作で初めて作成・再開します。初期設定は音声ONで、右上から切り替えられます。BGMはミスに応じて音階と警告音が変化します。隠しタブでは停止し、使い終わった音声ノードを解放します。対応しない環境では無音で遊べます。

Firebase、外部API、解析、オンラインランキングは利用しません。結果画面だけに未有効の広告掲載予定枠を置いています。広告の配信・AdSense承認は本MVPの完成とは別です。問題文はゲームの設定で、実際の情報送信・削除・公開処理はありません。

## テスト

```sh
npm test
```

Node.js標準テストランナーのみを利用します。ブラウザ検証には開発依存のPlaywright 1.62.1を使用します。別ターミナルで上記HTTPサーバーを起動してから、`npm install`、`npx playwright install chromium webkit` を実行し、`npm run test:browser` / `npm run test:audio-browser` / `npm run test:keyboard` で再現できます。`/usr/bin/chromium` が存在する場合はそれを利用し、それ以外はPlaywrightの管理するChromiumを利用します。別の実行パスは `CHROMIUM_PATH`、サーバーURLは `GAME_TEST_URL`、出力先は `GAME_TEST_OUTPUT` で指定できます。PlaywrightのWebKitはSafari相当のエンジン検証であり、実機Safariそのものの検証ではありません。詳細はQA_REPORTを参照してください。実機での操作や音声の確認は自動ブラウザ検証とは区別しています。
