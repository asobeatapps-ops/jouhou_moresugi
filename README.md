# 情報、漏れすぎ。 / ASOBEAT

いつものオフィスに触れて、カオスな結末を探すブラウザゲームです。質問に答える形式から、**オブジェクトをタップ・長押し・ドラッグする自由探索**へ作り変えました。時間・行動回数の制限はありません。

公開先：https://asobeatapps-ops.github.io/jouhou_moresugi/

## 遊び方

1. 「オフィスをのぞく」で部長とあなたのチャットを表示。タップごとに1発言だけ進み、最後のタップで探索開始します。待っても自動では進みません。再挑戦は2発言の短い会話です。名前が、触れる物の目印です。
2. パソコンをタップすると、メール・AI・ロック・確認・転送のアイコンが並びます。押す長さや回数によって、反応が変わります。
3. 猫・赤い資料・パソコンは、つかんだまま運べます。置ける先が緑に光ります。何もない所で離すと元に戻り、ペナルティはありません。
4. 壁の赤いボタンを少し引くと外れます。外れたボタンは重力で落ち、壁や床で跳ね返り、床で転がって減速します。何度でも拾って投げられ、窓とゴミ箱に新しい結末があります。取り外した後の壁にはボタンも当たり判定も残りません。巨大ボタン・壁ボタン長押しによる変化は廃止し、END09は元の壁ボタンを繰り返しタップする形で残します。冷蔵庫や引き出しも開閉できます。
5. 結末を見たら、図鑑に保存して再挑戦。カードを選ぶとそのカードに「ヒントをみる」が現れます。押すとそのまま手がかりを読めます。広告の準備表示・確認ステップはありません。カード選択だけではヒントを表示しません。手がかりは操作回数・秒数・組み合わせの正解を直接書かない内容です。探索中に図鑑を開いても続きに戻れます。図鑑から発見数と達成率を`#情報漏れすぎ`付きでXへ共有できます。Xの投稿作成画面を開くだけで、自動投稿はしません。
6. 全17ENDを発見すると、感謝の全画面を表示し、X共有かタイトルに戻る操作を選べます。達成済みなら図鑑からお祝い画面を再表示できます。

スマホは指、PCはマウスで操作します。キーボードはTabで対象を選び、Enter／Spaceでタップ・長押しできます。運べる物でPを押すと持ち上げ、Tabで置ける先を巡回し、Enterで置きます。Escでキャンセル。壁のボタンはPの後、矢印で動かしてEnterでも引き抜けます。

従来15ENDのID・名前・発見済み記録を引き継ぎ、END16・17を追加しました。説明文は全17種をよりカオスな内容に改訂しています。真END15は、END16・17も含むほかの16ENDをすべて発見後、新たに探索を始めて「あなた」に触れると見られます。旧版の質問・5問制・採点・ミス制は廃止したまま、開始時の会話を復元しました。

## グラフィックと入力

操作対象の丸い目印とPC用キー説明は表示しません。名前・選択枠・置き先ハイライトを残しています。Canvasで描いた机・モニター・資料・猫・人物・冷蔵庫・窓を、同じ木目／セージ色のオフィスに配置しています。遠近感のある床、厚み、光沢、床の影、開閉、猫のしっぽなどを描画し、写真や外部画像を読み込みません。選択枠・操作ラベル・持ち上げた物の影・置き先のハイライトで、操作対象を区別します。各対象のヒット領域は最低44 CSSピクセルです。

ドラッグの開始は8 CSSピクセル移動後。1本のポインターと操作トークンで重複入力・古い指のリリースを排除します。画面回転・リサイズ・pointercancelで操作を解除。フォーカス喪失・別タブでは探索とBGMを一時停止し、再開ボタンで戻ります。長押しだけには成立条件がありますが、探索全体には締切がありません。2回押しは離した時刻の間隔240ms以下です。

描画は最大30fps、DPR上限2。画面比率を変えても個々の絵の縦横比を維持します。小画面は縦スクロールできます。動きを減らす設定では探索の揺れ・CSSアニメーションを抑制します。

## ファイル構成

- `index.html` / `css/style.css`：タイトル・会話・探索・END・図鑑、PC内のウィンドウとヒント用ダイアログ、スマホ用配置
- `js/data.js`：11個の操作対象（外れたボタンは出現後に操作可能）、5アプリ、17ENDと攻略ヒント
- `js/intro.js`：タップでのみ進む会話、古い入力の排除
- `js/engine.js`：探索状態、操作の所有権、組み合わせ、長押し・二度押し、END確定
- `js/office-layout.js`：画面配置とドロップ判定座標
- `js/office-art.js`：オフィスと物の立体的なCanvas描画
- `js/button-physics.js`：外れたボタンの固定時間刻みの重力・跳ね返り・摩擦・転がりと高速投射の横断判定
- `js/share.js`：全17種を基準にした達成率とX共有URL
- `js/office-input.js`：指・マウス・キーボード入力、持ち上げ表示とキャンセル
- `js/main.js`：画面遷移、図鑑、保存・音声との接続
- `js/art.js`：人物の共通描画と既存17ENDアニメーション
- `js/storage.js` / `js/audio.js`：既存のローカル保存、生成BGM／SE
- `privacy.html` / `assets/favicon.svg` / `.nojekyll`：公開用ファイル
- `tests/`：状態・入力・画面・保存・音声の検証
- `DEVELOPMENT_SPEC.md`：元の指示書と承認された改訂
- `QA_REPORT.md`：今回の検証と限界

## 保存・広告・プライバシー

保存キー`asobeat_jouhou_moresugi_v1`を維持し、発見END、音声設定、プレイ回数、直近50回の履歴を保存します。旧版のベスト・最大コンボ・勤務完了履歴も破棄しません。探索版は採点せず、過去の最高値を上書きしません。保存拒否・破損時もメモリ上で遊べますが、保持できない旨を表示します。端末間共有はありません。

Web Audioはユーザー操作後に初めて起動します。右上からON/OFF可能です。音声を使えない環境でも遊べます。

結果画面の広告予定枠は、従来どおり結果操作部のゲームホームリンク下にあります。ヒント画面には広告枠や「広告掲載準備中」の表示を設けません。現在は未承認のため広告配信コードは未設置です。承認後の実配信を追加する場合は別の変更として設定してください。AdSense審査・広告配信の開始とは別の変更です。Firebase・外部API・解析・オンラインランキングは利用しません。ゲーム内の送信・削除・公開はすべてフィクションです。

## 起動・テスト・公開

```sh
python3 -m http.server 8020
```

http://localhost:8020/ を開きます。ES Modulesのため`file://`で直接開かないでください。公開時のビルド・サーバーAPI・秘密鍵は不要です。

```sh
npm test
npm install
npx playwright install chromium webkit
npm run test:browser
npm run test:keyboard
npm run test:touch-browser
npm run test:office-updates
npm run test:intro-hints
npm run test:mobile-gestures
npm run test:audio-browser
```

ブラウザテストには別ターミナルのHTTPサーバーが必要です。`GAME_TEST_URL`・`GAME_TEST_OUTPUT`・`CHROMIUM_PATH`でURL・出力先・Chromium実行ファイルを指定できます。`/usr/bin/chromium`があれば利用し、それ以外はPlaywright管理のChromiumを利用します。WebKitによるiPhone相当の検証は実機Safariのテストとは区別してください。

GitHub Pagesは **Deploy from a branch / main / (root)** を利用します。公開用ファイルをそのまま配信できます。依存パッケージやテスト結果を公開用にアップロードする必要はありません。


## 公開準備とスマホ操作の修正（2026-11-23）

ヒントはカード内ボタンから直接表示します。ゲーム内の二度押し・長押し・ドラッグと全17ENDは維持し、プレイ画面でのブラウザ側のダブルタップ拡大・文字選択・長押しメニュー・ピンチを抑制しました。タイトル／図鑑などでのズームは全体設定で禁止していません。`js/mobile-gestures.js`がブラウザの既定動作だけを抑え、ゲームのPointer Eventsは消費しません。
